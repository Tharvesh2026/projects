About the Project

Stop writing dummy
backends just to
practice frontend.

We built this open-source API to eliminate the friction of starting a new project. Get instant access to realistic datasets with full CRUD capabilities.

Whether you are building an ecommerce store, a recipe app, or a student management system, this server provides you with instant, fully-functional REST APIs backed by an in-memory database. Run it locally, hit the endpoints, and watch your application come to life.
